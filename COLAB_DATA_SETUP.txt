What Mounts Where:

GOOD (Persistent):
  ✓ Save to /content/drive/MyDrive/...  (stays on Drive)
  ✓ Mount is persistent across sessions

BAD (Ephemeral):
  ✗ Save to /tmp/ or /root/...         (deleted when runtime stops)
  ✗ Don't copy large files to /tmp

  /content/drive/MyDrive/gastric_tme_project/outputs/FINAL_PUBLICATION/

================================================================================
TROUBLESHOOTING
================================================================================

Q: "gasric_meta_integrated.h5ad not found"
A: Data isn't on Drive yet. Upload gastric_tme_project folder to Google Drive.

Q: "Still getting numpy error"
A: Make sure you're using COLAB_PRODUCTION_READY.py
   (It has the version fixes at the top)

Q: "Training is taking too long / running out of memory"
A: Normal for 766k cells. A100 takes 4-6 hours.
   Use Ctrl+C if you need to stop, but let it finish.

Q: "Can I run this without uploading everything?"
A: Not easily. You need the h5ad files (they're binary, ~3-5 GB).
   Upload once to Drive, reuse forever.

Q: "Download is slow from Drive"
A: Normal. 3 small PNGs + 1 TXT file should download in <1 min.

Q: "Runtime crashed at hour 3"
A: Colab has 12-hour timeout (usually). Restart and re-run, it'll resume.
   Model saves to Drive so progress isn't lost.
